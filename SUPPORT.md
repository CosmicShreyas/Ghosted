# Support

Use GitHub Discussions for setup questions, product ideas that are not yet concrete proposals, and help understanding the codebase. Use an issue when you can describe a reproducible bug or a specific, actionable improvement.

Before asking for help:

1. Read the root, API, admin, and Supabase READMEs relevant to your task.
2. Search existing issues and discussions.
3. Remove secrets and personal data from logs and screenshots.
4. Include your operating system, Node.js version, command, and complete error message.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting publicly.
